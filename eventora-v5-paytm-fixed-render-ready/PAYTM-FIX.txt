PAYTM ERROR HANDLING FIX

This version handles temporary/non-JSON Paytm gateway responses safely.

If Paytm returns text such as:
no healthy upstream

the website will now show:
Paytm service temporarily unavailable. Please try again shortly.

DEPLOY:
1. Replace the files inside your existing GitHub folder:
   eventora-v5-paytm-render-ready
2. Commit the changes.
3. Render -> Manual Deploy -> Deploy latest commit.

This fix does NOT create Paytm merchant credentials.
You still need a valid Paytm MID + Merchant Key for actual Paytm payments.
