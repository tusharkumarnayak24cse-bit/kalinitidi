EVENTORA V4 - RENDER DEPLOYMENT

This package is designed to replace your current Eventora deployment.

MAIN UPGRADES
- PostgreSQL persistent database
- Razorpay checkout support
- Email ticket delivery via SMTP
- WhatsApp confirmations via Twilio
- QR ticket page
- Phone-camera QR scanner
- Duplicate check-in prevention
- Admin dashboard

UPLOAD
1. Extract this ZIP.
2. Replace the files in your GitHub app folder with these files.
3. Commit the changes.
4. In Render, deploy the latest commit.

IMPORTANT: if your Render Root Directory is currently:
eventora-railway
either:
A) upload these V4 files INSIDE that same eventora-railway folder, OR
B) change Render Root Directory to whatever folder contains this package.json.

RENDER SETTINGS
Build Command: npm install
Start Command: npm start

POSTGRESQL
Create a Render PostgreSQL database.
Copy its Internal Database URL to your Web Service variable:
DATABASE_URL

REQUIRED VARIABLES
JWT_SECRET = a long random secret
ADMIN_EMAIL = your admin email
ADMIN_PASSWORD = a strong password
PUBLIC_BASE_URL = https://your-service.onrender.com

RAZORPAY
RAZORPAY_KEY_ID
RAZORPAY_KEY_SECRET
RAZORPAY_WEBHOOK_SECRET

EMAIL (SMTP)
SMTP_HOST
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER
SMTP_PASS
FROM_EMAIL

WHATSAPP (TWILIO, optional)
TWILIO_ACCOUNT_SID
TWILIO_AUTH_TOKEN
TWILIO_WHATSAPP_FROM
