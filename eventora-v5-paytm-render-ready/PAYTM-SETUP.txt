EVENTORA V5 - PAYTM + RAZORPAY

This version adds Paytm Payment Gateway alongside Razorpay.

HOW TO REPLACE YOUR CURRENT LIVE VERSION
1. Extract this ZIP.
2. In your GitHub repository, open the folder Render currently uses as Root Directory.
   From your previous setup this is likely: eventora-railway
3. Replace the files in that folder with the files from this V5 ZIP.
4. Commit changes to main.
5. Render -> Manual Deploy -> Deploy latest commit.

PAYTM VARIABLES TO ADD IN RENDER
PAYTM_MID = your Paytm Merchant ID
PAYTM_MERCHANT_KEY = your Paytm Merchant Key
PAYTM_WEBSITE = WEBSTAGING
PAYTM_ENV = staging

For live Paytm later:
PAYTM_WEBSITE = your production website name from Paytm dashboard
PAYTM_ENV = production

Also keep:
PUBLIC_BASE_URL = https://tusharevent-1.onrender.com

Paytm callback is automatically:
https://tusharevent-1.onrender.com/api/paytm/callback

RAZORPAY VARIABLES
RAZORPAY_KEY_ID
RAZORPAY_KEY_SECRET
RAZORPAY_WEBHOOK_SECRET

IMPORTANT
Start with Paytm staging/test credentials.
Do not put merchant secret keys into GitHub.
Put secrets only in Render Environment Variables.
QR tickets are generated only after server-side payment verification.
